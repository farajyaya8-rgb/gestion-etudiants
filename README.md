# Gestionnaire d'étudiants en Python

Application console permettant de gérer une liste d'étudiants :
ajout, affichage, recherche, modification, suppression et statistiques.
Les données sont sauvegardées automatiquement dans un fichier JSON.

## Fonctionnalités

- Ajouter un étudiant
- Afficher la liste des étudiants
- Rechercher un étudiant
- Modifier les informations d'un étudiant
- Supprimer un étudiant
- Calculer des statistiques
- Valider les saisies utilisateur
- Sauvegarder les données dans un fichier JSON
- Charger automatiquement les données au démarrage

## Technologies utilisées

- Python 3
- JSON
- Git
- GitHub
